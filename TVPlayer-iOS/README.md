# TVPlayer iOS 1.8 正式版

自签侧载版本的 **TVPlayer 正式版** 直播播放器。

## 版本

- **Marketing Version:** 1.8  
- **Build:** 180  
- **显示名:** TVPlayer 正式版  

## 功能

- 横屏全屏直播
- 自定义 M3U / M3U8 源
- 多线路自动切换
- 收藏 / 隐藏线路
- 后台音频、数字键与手势操作

## 发布

```bash
git tag v1.8-ios
git push origin v1.8-ios
```

GitHub Actions 会构建 IPA 并创建 Release。
